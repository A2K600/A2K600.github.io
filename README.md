# Portfolio – Antoni Kryk

Automatyzacja danych, dashboardy i strony www dla małych firm.

**Strona:** otwórz `index.html` albo wersję online na GitHub Pages.

| Projekt | Co pokazuje | Technologie |
|---|---|---|
| [Automatyczny raport sprzedaży](projekty/raport-sprzedazy/) | czyszczenie 3 „brudnych” plików i raport Excel z wykresami | Python, pandas, openpyxl |
| [Dashboard sprzedaży](projekty/dashboard/) | interaktywne filtry i wykresy w przeglądarce | JavaScript, SVG |
| [Strona warsztatu](projekty/warsztat/) | responsywna strona lokalnej firmy z formularzem | HTML, CSS, JS |

Dane i firmy w projektach są fikcyjne.
